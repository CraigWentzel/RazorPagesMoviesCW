# RazorPagesMoviesCW

An ASP.NET Core Razor Pages movie catalogue application built with C#, Entity Framework Core and SQLite.

## Overview

This application allows users to manage a movie catalogue through a web interface. Users can create, edit, view and delete movies, upload movie posters, and search through the catalogue.

## Features

- Create, Edit, Delete and View Movies
- Movie Search and Filtering
- Movie Rating Validation
- Poster Image Uploads
- Poster Replacement
- Poster Thumbnails on the Movie List
- Full Poster Display on Details Page
- SQLite Database Storage
- Entity Framework Core Integration
- Responsive Bootstrap User Interface

## Technologies Used

- ASP.NET Core Razor Pages
- C#
- Entity Framework Core
- SQLite
- Bootstrap
- Git
- GitHub

## Screenshots

### Movie List
Displays all movies with poster thumbnails.

### Movie Details
Displays complete movie information and full-size poster.

### Movie Edit
Allows movie details and poster images to be updated.

## Getting Started

### Prerequisites

- .NET 10 SDK
- Visual Studio Code or Visual Studio

### Run the Application

```bash
dotnet restore
dotnet build
dotnet run
```

Open the application in your browser using the URL displayed in the terminal.

## Database

The application uses SQLite and Entity Framework Core for data storage.
