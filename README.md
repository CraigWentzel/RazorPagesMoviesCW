# RazorPagesMoviesCW

An ASP.NET Core Razor Pages movie catalogue application built with C#, Entity Framework Core and SQLite.

## Overview

This application allows users to manage a catalogue of movies through a web interface. Users can create, edit, view and delete movies, upload poster images, and search through the movie catalogue.

## Features

- Create, Edit, Delete and View Movies
- Search and Filter Movies
- Movie Rating Validation
- Poster Image Uploads
- Poster Replacement
- Poster Thumbnails on Movie List
- Full Poster Display on Details Page
- SQLite Database Storage
- Entity Framework Core Integration

## Technologies Used

- ASP.NET Core Razor Pages
- C#
- Entity Framework Core
- SQLite
- Bootstrap
- Git
- GitHub

## Getting Started

### Prerequisites

- .NET 10 SDK
- Visual Studio Code or Visual Studio

### Run the Application

```bash
dotnet restore
dotnet build
dotnet run
```
